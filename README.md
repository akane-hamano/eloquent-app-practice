# eloquent-app-practice

## 概要
COACHTECH 教材 Tutorial 9-4「Eloquent ORM ハンズオン演習」で作成した成果物です。
Eloquentモデルを使って「ブログシステム」の投稿一覧機能（投稿の作成、編集、削除）を作成しました。

## 使用技術
- PHP 8.x
- Laravel 10.x
- Eloquent ORM
- MySQL

## 学んだこと
- Eloquent モデルを使ったCRUD操作
- リソースコントローラの役割について

## 動作確認
ブラウザで http://localhost/posts にアクセスし、投稿一覧が表示され、投稿の追加、更新、削除ができれば成功となります。
